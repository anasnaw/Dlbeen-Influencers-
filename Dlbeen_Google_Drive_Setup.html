DLBEEN GROUP / INFLUENCER MARKETING

Connect the system to your Google Drive

The Google Sheets database is ready to use. This one-time setup allows the private web interface to read and save records, upload profile photos, and save PDF and Excel reports in the same Google Drive folder.

Current status: authorization required.
The ChatGPT Google Drive connection does not automatically authorize an independently hosted web app. No influencer records have been invented or pre-filled. The app’s sample workspace is fictional and read-only.

Your files

  • Open the database in Google Sheets
  • Open the system folder in Google Drive
  • Open the private web interface

1. Add the prepared script

  1. Open the Dlbeen Google Sheet using the same Google account that owns it.
  2. Choose Extensions → Apps Script.
  3. Open the prepared Code.gs file from your system folder or download it here. Copy all its text into the Apps Script editor, replacing the empty starter code.
  4. Name the project Dlbeen Influencers System and save.

2. Initialize and authorize

  1. In the Apps Script function selector, choose initializeSystem, then click Run.
  2. Complete Google’s authorization flow for the project you just created. The script uses Google Sheets, Google Drive and Google’s export service; it does not send emails.
  3. Return to the spreadsheet and reload it. Open Dlbeen → Show connection key.
  4. Keep this key private. It grants access to the prepared database and its uploaded photos. Paste it only into your private system’s connection form.

Initialization creates Photos and Reports folders and an Activity tab. It does not change the sharing permissions on your database or folder.

3. Deploy the connection

  1. In Apps Script choose Deploy → New deployment.
  2. Select the deployment type Web app.
  3. Set Execute as: Me.
  4. Set Who has access: Anyone, then deploy. This makes the connection endpoint reachable by the private app’s server; every data request still requires the secret connection key. Visiting its URL exposes no records. Keep the Google Sheet and Drive folder private.
  5. Copy the web app URL ending in /exec.

If your Google Workspace administrator does not allow this deployment type, ask the administrator for an approved integration route. Do not make the spreadsheet public.

4. Test the connection

  1. Open the private Dlbeen system and choose Settings & connection.
  2. Paste the web app URL and the connection key.
  3. Click Test & save connection. The system tests the endpoint before storing the connection settings.
  4. Create one real influencer and confirm it appears in the Google Sheet. Then add their monthly agreement and content records.

Daily workflow

Influencer → Monthly agreement → Content → Reports. Log each story frame, reel or post separately. Only Published content counts toward delivery. Update its metrics from creator insights, then choose Yes, No or Maybe for renewal. Copy agreements to a new month to preserve history.

Reports are filtered by agreement month, brand, influencer and currency. Download PDF / Export Excel saves to your device. Save PDF / Excel to Drive saves into the Reports folder and retains the manager’s notes.

Capacity and maintenance

The prepared spreadsheet supports 200 profiles, 300 monthly agreements and 1,500 content items. To expand it, extend the input tables, formula rows, lookup ranges, reporting ranges and script limits together. The app stops adding new rows when the prepared capacity is reached. Google Apps Script quotas apply to connected saving and exports.

After a script update, publish a new version under Deploy → Manage deployments, keeping the same deployment URL. The private app stores only the endpoint and connection key; influencer records and photos are stored in your Google account.

Troubleshooting

  • Authorization error: run initializeSystem again in Apps Script and complete Google’s flow.
  • Invalid key: copy it again from the Dlbeen menu; do not paste spaces or quotes.
  • Record changed: refresh before editing again. Direct edits in Google Sheets should be followed by Refresh in the app.
  • Missing metrics: leave unknown figures blank; enter zero only for a measured zero.
